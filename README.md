# Shopify Snippets

Free Shopify theme snippets by [KondaSoft](https://www.kondasoft.com) that you can use in Dawn or any other Shopify theme.

You don't have to edit your theme's own files to install them, so updating your theme stays easy. Each snippet is mostly a single file you copy and paste, and its download includes an installation guide.
